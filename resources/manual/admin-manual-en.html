2) Before You Start (2 Minutes)

  • Use one browser tab for this system.
  • Do not use the browser Back button while filling forms.
  • After clicking Save, wait for the page to finish loading.
  • Never share your password.
Warning: Clicking many times can create duplicate actions.

Login

1

2
Type username and password.
3
Click Login.
4
Confirm you can see the left menu.

Logout

1
Click Logout in top-right area.
2
Wait for login page to appear.

4) Understand The Screen

Top bar Home, language switch, notifications (bell), profile, logout.
Left menu Services, Add customer, Reports, Seasons, Bonus, Locations, Equipment, Cards, Customers, Issues, Users.
Main area Forms, tables, filters, save buttons.

5) Golden Rules To Avoid Mistakes

  1. Save once, then wait.
  2. Do not refresh while saving.
  3. Do not close tab while saving.
  4. Use left menu to navigate, not browser Back.
  5. Double-check money values before save.
Important: If you are unsure, stop and check before saving.

6) Main Modules

Services module (Menu: ServicesURL: /services)

Purpose: controls the base service records used by seasons, bookings, pricing, and reports.

Use it when: creating a new service, updating service name, activating/deactivating service, or checking setup.

  1. Open Services and select the target service.
  2. Check service title and active status.
  3. Confirm there is an active/valid season in Seasons.
  4. Confirm linked entities (locations, cards, equipment) if used by that service. Locations are grouped as Main (all services) and Custom (single service).
Operational tip: Do not deactivate a service with active bookings before validating impact with the team.

Booking module (Menu: Add customerURL: /crm/bookings)

Purpose: creates a booking for a customer with service, dates, location, and payment data.

Flow: identify the customer first, then complete booking details.

  1. Select an existing customer or choose New customer.
  2. Select service type and specific service.
  3. Select season, dates, and location (when required). For service bookings, location must be from Main locations or Custom locations for that service.
  4. Fill payment fields and click Save once.
  5. Verify the result in the customer profile and unpaid-fees view (if there is remaining balance).
Common failure reason: missing required field, invalid season/date match, missing location, or location not allowed for selected service.

Reports module (Menu: ReportsURL: /reports)

Purpose: shows summarized booking/payment data by service and period.

Minimum steps for correct report output:

  1. Select the correct service.
  2. Select start and end date range.
  3. Click Generate and wait for results.
  4. Review row-level data (including location) and totals before export.
  5. Use CSV export or Print when needed.
If report is empty: widen date range first, then test with a known active service.

Seasons module (Menu: SeasonsURL: /seasons)

Purpose: manages date periods per service. Booking dates depend on valid season periods.

  1. Each service has separate seasons with start/end dates.
  2. Seasons for the same service must not overlap.
  3. Before high-volume booking days, confirm period coverage.
  4. Adjust/create season before entering bookings for new period.
  5. Do not delete seasons that already contain active bookings.
Critical: Incorrect season setup causes booking date errors and incomplete reports.

7) Daily Tasks

Task A: Add new booking (Menu: Add customerURL: /crm/bookings)

When to use: A customer or parent requests a booking.

Before you start: Customer name, birth date, parent phone, service, dates, payment data.

1
Open Add customer.
2
Select an existing customer or choose New customer.
3
Choose service type and continue.
4
Enter the customer, service, season, dates, and location. Use Main or matching Custom location.
5
Fill payment fields and save.

Expected result: Booking saved and visible in related pages.

If it fails: Check missing required fields, date selection, and that selected location is valid for the service.

Task B: Find customer (Menu: CustomersURL: /customers)

1
Open Customers.
2
Use search field (name, phone, email).
3
Open customer profile and review details.

Task C: Record payment (Menu: Customers > Unpaid feesURL: /customers/unpay)

1
Open Unpaid fees.
2
Find the customer in the table.
3
Enter payment amount and save/update.
4
Confirm remaining amount decreased.

Task D: Generate report (Menu: ReportsURL: /reports)

1
Open Reports.
2
Select service and date range.
3
Click Generate.
4
Optional: export CSV or print.

Task E: Check seasons (Menu: SeasonsURL: /seasons)

1
Open Seasons.
2
Find service and verify season dates.

Task F: Report issue (Menu: IssuesURL: /issues)

When to use: Something is broken, missing, or showing wrong data.

1
Open Issues and click New issue.
2
Select module, issue type, and priority.
3
Fill short title and clear description.
4
Optional: add page URL and up to 3 screenshots (5 MB each).
5
Submit and track the ticket by status/comments.

Expected result: Ticket is created with number and visible status (Open/In progress/Resolved).

Note: Only super admin can change status or assignee.

Task G: Check notifications (Top bar: Bell icon)

When to use: During the day, to track assigned issues and important updates.

1
Check the bell icon in the top bar. The badge shows unread count.
2
Click the bell and open one notification item.
3
The system opens the related page (for example issue details or customer profile).
4
After opening one item, unread badge decreases by one.

Common notification types: issue assignment/status/comments; manager updates visible to admins (bookings, customers, services, payments).

8) Weekly And Monthly Tasks

  • Services (/services): verify active services and settings.
  • Cards + Equipment (/cards, /equips): verify prices and linked services.
  • Locations (/locations): verify naming, group assignment (Main vs Custom), and duplicate routes.
  • Users (/users): verify active staff access and role correctness.

9) Admin And Manager Tasks

Add new user

  1. Open Users.
  2. Click Add user.
  3. Fill details and role.
  4. Save and ask user to test login.

Check logs (if available for your account)

  1. Open Logs.
  2. Review unusual repeated failures.

10) Troubleshooting Quick Guide

Cannot login Check Caps Lock, keyboard language, and retry slowly. If still blocked, request password reset.
Page is slow or frozen Wait at least 10 seconds, reload once, then logout/login if needed.
Booking does not save Confirm required fields, selected dates, and selected location. For service bookings, location must be Main or Custom for the chosen service.
Payment update not visible Reload unpaid list, then verify in customer profile.
Report is empty Check service and date range, then retry with known active period.
Wrong language on screen Use BG/EN switch in top bar and refresh once.

11) End-Of-Day Checklist

  • [ ] Confirm all new bookings are visible.
  • [ ] Confirm payment updates are visible.
  • [ ] Review unread notifications in the bell menu.
  • [ ] Export/print report if required.
  • [ ] Logout from system.
  • [ ] Close browser.
